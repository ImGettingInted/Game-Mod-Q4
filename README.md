DND Quake 4e
This game is played similarly to the original quake game, once in-world, but there is one important difference before loding in. Upon starting a new game, the player is prompted to create a character. 
They may choose between 4 different classes:
The Fighter, The Bard, The Ranger, and the Wizard. 
These 4 classes each come with different starting stats, which will increase upon killing enemies and leveling up.
When fighting enemies, A random number is rolled from 1-20 and is compared against the targets "armor class" to determine whether the attack will succeed or not.
